# Partner header and account menu

Production: https://partner.traverion.com

The shared header is 53px. The profile button sits centered with 8px of room on each side, including its focus outline. Home, Calendar, and Bookings use the same height.

The account menu is a menu button. Account name and email sit above the actions. Account settings and Sign out have icons, hover, and keyboard focus. Arrow keys move between them. Escape returns focus to the button. A click outside, or choosing an item, closes the menu. On a 390px screen the menu stays inside the viewport.

13/13 PASS on desktop and mobile. Chunk `SupplierLayout-DTJL6oiY.js`.
